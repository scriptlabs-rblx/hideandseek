Main Game

This document will explain how to configure the main game. The configuration module contains information from text statuses, all the way to compatibilities and enums.

Asset Settings​

Voting Model​

["VOTING_MODEL"] = ..., -- Model

Voting model that handles both mode and map voting

❗Please be sure to have a similar model hierarchy for the voting model to the following hierarchy:❗​

├── VoteStation (Model)
│   ├── 1 (Model)
│   │   └── Information (BasePart)
│   │   │   └── Gui (SurfaceGui)
│   │   │   │   ├── Image (ImageLabel)
│   │   │   │   ├── Title (TextLabel)
│   │   │   │   └── Votes (TextLabel)
│   ├── 2 (Model)
│   └── 3 (Model)
└──

Spawn Part​

["SPAWN_PART"] = ..., -- BasePart

Spawn part for lobby (will be converted to table for multiple spawns in the future)

Information Strings​

Intermission Text​

["INTERMISSION_TEXT"] = "...", -- string

Text to display during the intermission

Map Voting Text​

["MAP_VOTING_TEXT"] = "...", -- string

Text to display while voting for a map

Mode Voting Text​

["MODE_VOTING_TEXT"] = "...", -- string

Text to display while voting for a gamemode

Map Chosen Text​

["MAP_CHOSEN_TEXT"] = "...", -- string

Text to display after a map has been chosen

Mode Chosen Text​

["MODE_CHOSEN_TEXT"] = "...", -- string

Text to display after a gamemode has been chosen

Game Starting Text​

["GAME_STARTING_TEXT"] = "...", -- string

Text to display before the game starts

Round Text​

["ROUND_TEXT"] = "...", -- string

Text to display while the round is ticking

Choosing Roles Text​

["CHOOSING_ROLES_TEXT"] = "...", -- string

Text to display while choosing player roles (either Seeker or Hider in V1.0.0)

Round Over Text​

["ROUND_OVER_TEXT"] = "...", -- string

Text to display after the round is completed

Hiders Win Text​

["HIDERS_WIN_TEXT"] = "...", -- string

Text to display if the hiders won the round

Seekers Win Text​

["SEEKERS_WIN_TEXT"] = "...", -- string

Text to display if the seekers won the round

Draw Text​

["DRAW_TEXT"] = "...", -- string

Text to display if nobody won the game

Timers​

Intermission Time​

["INTERMISSION_TIME"] = ..., -- number

How long players wait before beginning voting

Map Voting Time​

["MAP_VOTING_TIME"] = ..., -- number

How long players can vote for a map

Mode Voting Time​

["MODE_VOTING_TIME"] = ..., -- number

How long players can vote for a gamemode

Delay Time​

["DELAY_TIME"] = ..., -- number

Delay between messages like x gamemode has been chosen!

Game Starting Time​

["GAME_STARTING_TIME"] = ..., -- number

Time before the round starts after voting

Round Time​

["ROUND_TIME"] = ..., -- number

Maximum amount of time a round can last before being forcefully stopped

Seeker Hide Screen Time​

["SEEKER_HIDE_SCREEN_TIME"] = ..., -- number

Time that players have to hide (Seekers screen is black during this time)

Game Settings​

Minimum Players​

["MIN_PLAYERS"] = ..., -- integer

Minimum amount of players before a round can start

Seeker Hitbox Size​

["SEEKER_HITBOX_SIZE"] = Vector3.new(...), -- Vector3

Size of the hitbox in front of the seeker when they click

Compatibility Settings​

Compatibility​

["COMPATIBILITY"] = {
    ["MOBILE"] = {
        ["ACTION_GUI"] = ..., -- boolean
	},
},

Gui for mobile players to use; for example, hitting when they are the seeker

KeyCodes​

["KEYCODES"] = {
    ["HIT"] = { -- Mobile automatically has it's own touch input
        ..., -- Enum.KeyCode | Enum.UserInputType
    },
},

Set of key codes used for game actions

info

V1.0.0 of the Hide and Seek Roblox Template uses hitting (similar to tag), instead of line of sight (traditional hide and seek). In future updates, there will be added systems for choosing hitting or LoS.
